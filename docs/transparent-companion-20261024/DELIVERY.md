# 透明形象接入动态伙伴预览

已在真实 uni-app 页面中接入服务商原始透明 PNG，默认从设置的“动态伙伴 → 试放透明形象”进入。试放素材与宠物资料分开，不写入宠物头像或首页显示设置。

## 查看

- 本机预览：http://127.0.0.1:4208/#/pages/dynamic-companion/dynamic-companion?preview=native-alpha
- 入口：设置 → 界面与显示 → 动态伙伴 → 试放透明形象。
- 页面内可隐藏/恢复试放；图片失败时可重新载入。该版本是静态透明形象，不是动画。

## 本轮调整

- 扩大原来空白的宠物区域，按真实 alpha 主体边界安排显示尺寸与水平位置，完整保留耳尖、尾巴和脚爪。
- 形象直接融入深暖背景；移除试放时的预留圆圈，使用轻微页面承托阴影。没有照片卡、白底、蒙版或 alpha 清理。
- 陪伴/怀念的文字和原记录入口保持各自逻辑；明确标注试放素材，真实记录标明所属宠物。
- 未修改首页源码，未调用付费模型或部署云端。
