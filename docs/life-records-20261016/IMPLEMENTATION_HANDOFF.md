## 保护范围与实现边界

沿用现有 scoped-storage、diary/narrative、媒体与卡片模块，没有第二套账号/宠物/记录库。新增适配层见 source manifest。旧日记录仍按原格式保留；同日新增用独立 ID。元数据不冻结旧健康正文；删除后旧编辑器不能通过迟到保存复活来源。冻结作品仍独立保存；删除来源时明确选择是否一并删除关联作品。

基线核对 114 个已有客户端文件，12 个为本轮有意修改，其余 102 个字节不变；名单见 `baseline-comparison.json`。其中 App.vue、pages.json、manifest.json、首页主体、主视觉、账号与会员模块未被本轮改写。仓库开始时就有大量未提交改动，未 reset/clean/stash/commit/push。回滚须以 `baseline/source/` 与本轮 source manifest 为边界，不能用 HEAD 整体覆盖当前工作。

保留既有 1/3/7 不连续生活日及月册门槛/前置收据规则；本轮按 W-03 修正“纯健康记录不算生活有效日”，不追溯删除旧收据，不改变会员权益。月册仍沿用已存在的 7 日收据前置规则，没有擅自重新设计奖励。

敏感回看使用用途、健康字段、私密补充、隐藏标记及保守文字规则，不是能理解任意文本的语义分类器。用户仍可关闭或逐条隐藏；不宣称能准确识别所有健康含义。作品手动编辑不修改原始观察。

## 未验证项与限制

- 98 项矩阵逐项结果见 `ACCEPTANCE_RESULTS.md`。未执行的 UI/异常组合仍为 NOT_RUN；平台缺失为 BLOCKED，不能据此宣称发布全验收。
- 原生照片复制/权限拒绝、系统相册保存、Android 冷启动/返回/后台恢复、多指手势和旧 WebView 需要集中验收。
- 当前测试的 125% 根字号设置不是 Android 系统大字体。移动软键盘、系统安全区、无障碍字体和长宠物名组合未实测。
- 1000 条记录仅测了隔离 Node 元数据查询；不是 1000 张照片的真机性能结论，没有制定虚构设备毫秒门槛。
- H5 本机 IndexedDB 不等于云备份或跨设备同步；原生路径不能由 H5 结果证明。
- 后续重开/删除范围、敏感开关的主要逻辑已测试，但所有作品参数与设备组合未穷举。
- 本轮曾出现的测试失败、原因与修复见 `FAILURES_AND_RERUNS.md`，历史失败证据保留。
