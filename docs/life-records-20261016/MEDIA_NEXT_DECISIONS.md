# 媒体下一轮待决策 · 2026-10-16

当前实际路径：统一记录器最多沿用 4 张主动选图，支持说明、排序、用途和明确移除引用；H5 存真实 Blob 到现有 IndexedDB，App 代码沿用 PRIVATE_DOC/pety-narrative-media 复制，其他端沿用现有保存文件接口。H5 已实测，原生路径本轮未实测。未新建上传服务或视频入口，现有宠物高清母版与缓存不参与记录照片删除。

来源链：账号域/宠物 → 原始记录 ID/版本/事件精度 → 照片资产 ID/用途 → 作品选材配方（顺序、文字版本、日期显示、取景） → 冻结静态作品与导出 PNG。改配方不改原图/原文；源被删除时自动候选失效，独立作品按用户明确选择处理。缩略图可再建，不能据此删除唯一源资产。

当前真实状态有选图/本机保存中、可用、明确失败、来源缺失、作品渲染失败、作品已入册、浏览器下载已发起；没有云任务，因此没有上传进度、已备份或假重试入口。照片失败保留文字草稿，用户可以重试或明确不带失败照片继续。H5 下载成功不写成系统相册成功。

下一轮需决定，而不是本轮替用户拍板：

1. 首批平台与照片/视频优先级；每条/每批数量、文件大小、视频时长和实际可接受质量。
2. 原始文件、展示图、缩略图、视频播放版和封面分别保留什么；如何定义“原图”。
3. 跨设备/迁移/备份的承诺、容量、计量、价格、取消与失败恢复；再选择存储和服务器。
4. HEIC、Live Photo、方向/镜像、HDR、高像素、转发文件、无拍摄时间的处理；不能把导入日冒充拍摄日。
5. 大批导入、重复检测、弱网/后台/重启恢复与来源缺失；用户如何核对成功/失败每一项。
6. 视频只需保存/播放，还是需要封面选帧、非破坏性片段范围或真正导出短片；它们是不同能力。
7. 原音保留、静音预览与导出音轨选择；不默认加商业音乐、声音克隆或 AI 分析。
8. 源记录/共享引用/独立作品分别删除什么；原始资料按条/月/宠物/全部导出的范围。
9. 平台隐私说明和审核需更新哪些实际用途；选素材、制卡、给 AI、分享各自独立授权。

必须逐端核对项目实际 HBuilderX 版本对应的官方图像/视频 API：选择器权限与部分授权、临时路径生命周期、持久化字节、方向/尺寸、真实拍摄时间是否可得、编码/音轨可播性、选帧/片段能力、系统相册导出回调。官方入口 `https://uniapp.dcloud.net.cn/api/media/image.html` 与 `https://uniapp.dcloud.net.cn/api/media/video.html` 仅列作下一轮核对入口，本轮没有据此宣称平台支持。

M-01 至 M-08 全部 DEFERRED。没有视频文件就不能用封面冒充可播放成果；没有服务端确认就不能宣称云端保存。未引入 FFmpeg、转码云、付费插件、监控 SDK、RTSP 或新供应商。
