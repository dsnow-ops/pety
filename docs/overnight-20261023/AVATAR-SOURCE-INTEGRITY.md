# 头像原图上传凭据完整性

2026-10-23 09:23。本轮仅修改本地云函数源码并使用数据库、图片检查与模型替身测试；没有上传私人图片，没有真实模型或云调用，没有部署。

## 已确认的问题与修复

此前上传凭据查询只取可选的 data[0]，错误响应或缺失 data 可能被当作没有旧凭据；插入不检查回执也返回上传路径。完成凭据时，字符串更新计数会被接受，矛盾回执可能被忽略；NaN等损坏的到期时间和图片尺寸无法被原有大小比较拦住。

现在查询必须是明确成功的单行/空行响应。插入要求匹配的凭据ID，随后读取持久化记录；未知回执立即停止，本次不返回可用票据，也不重写或删除可能已存在的凭据。相同批次和槽位重试仍使用原ID，恢复原来的路径。

归属、宠物、会话、凭据ID、云空间和路径必须一致。issued/ready状态、到期时间、创建时间以及ready摘要/字节数需要合法值。完成检查使用有限的正整数尺寸和字节数；检查图片后再次判断是否过期。更新带上原归属、会话、文件和到期条件，并在明确回执之后确认持久化摘要和字节数。

如果更新实际已成功但回执不明，本次报告失败；后续重试读取同一份ready记录，不再次检查图片或改写摘要。两个相同完成请求可收敛到同一摘要，结果不同则拒绝。合法旧路径格式继续支持，没有更改15分钟票据时长、图片大小限制或会员额度。
