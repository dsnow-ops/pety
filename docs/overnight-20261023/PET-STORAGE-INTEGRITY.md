# 宠物存储：只读查询、失败恢复与损坏保护

2026-10-23 08:44。修改common/pet-store.js、“我的”页错误入口和共享主题读取容错。未修改首页构图文件，没有迁移、删除或读取真实用户资料。

## 实际行为

稳定宠物列表的读取不再写回列表、当前选择或旧版缓存。只有缺少稳定ID/时间的旧记录，以及仅有旧版缓存、没有列表的资料，执行一次明确的兼容迁移。明确的空数组不会从旧缓存复活宠物。

损坏列表、无效记录、重复ID和无效选择类型会停止读取/修改，保留原始存储。“我的”页显示重新读取入口，隐藏空白引导和新增/切换控件；共享主题入口提示到“我的”重试。恢复源数据后可重新读取。

新增、切换、更新宠物的列表、当前选择和兼容缓存接入现有scopedStorage可恢复事务。单个写入失败会回滚；回滚本身暂时失败则保留日志，下次成功读取前先恢复。写入途中账号切换也会恢复旧账号，不能写入新账号。重复显式ID拒绝新增，已存在的未知兼容字段保留。
