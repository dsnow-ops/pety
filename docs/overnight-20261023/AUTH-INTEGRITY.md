# 账号鉴权：查询故障不冒充注销

2026-10-23 07:07，本地源码修复，未部署云端。

已复现：用户查询返回 `data:[null]` 时，共享鉴权把它当作账号不存在；真实资料接口返回明确失效码，客户端随后清掉有效缓存令牌。另一方面，查询同时带错误码和用户行、损坏的令牌失效时间等结构可能被当作有效数据继续鉴权。

本轮在共享 `pety-auth/index.js` 收紧官方SDK与数据库回执检查。损坏响应、矛盾错误码、非唯一用户、显式不匹配的用户ID、无效状态/令牌数组/角色/权限/失效时间均报告账号服务暂时不可用，不授权业务，也不要求客户端注销。SDK明确失效、合法空账号查询、已撤销的令牌列表、封禁/审核/关闭状态继续按原规则拒绝。角色与权限仍从实时数据库读取，没有信任JWT内嵌权限或客户端声明身份。

## 边界

数据库和SDK响应来自本地测试替身，不是线上故障注入；未操作真实账号、令牌或云数据。部署前仍需在隔离云环境验证官方实际返回结构与真实注销/角色撤销，不能把291项本地通过写成线上验收完成。异常持久记录可能需要人工核对，不会在鉴权请求中自动修复或删除。
