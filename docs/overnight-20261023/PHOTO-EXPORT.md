# 生活照片批量保存

实际入口：陪伴册/纪念册 → 照片 → 选择照片保存。逐张勾选，或选择当前已展开的一页，然后保存。单次最多30张，原记录始终保留。

这个方向来自[亲宝宝官方发展历程](https://www.qinbaobao.com/about)列出的2026年6月照片视频批量下载能力。归爪本轮落地的是已有本机生活照片的明确选择与批量保存，没有宣称实现亲宝宝的云相册、视频下载、家庭共享或完整备份。

## 已实现

- 浏览器：将所选原图打包为一个ZIP发起下载，最多64MiB；不压缩重编码、不抠图、不上传。格式为PNG/JPEG/WebP/GIF，文件名使用原记录的准确日期；时间精度不足时使用date-unknown，不伪造日期。文件中不附带账号、token、照片说明、聊天或问诊正文。
- App：按顺序将原始本机路径交给系统相册接口；遇到相册保存失败就停下，避免反复弹权限请求。此分支已编译和模拟回调测试，真实手机相册结果仍待验。
- 每批显示结果；失败和未处理的照片保持选择，重试只处理这些项。已确认成功的照片不会自动重存。
- 用户可以停止后续保存。切换宠物/账号、页面离开或原记录变化，会阻止后续输出。原生系统已经接收的一次保存不能撤回，不能承诺取消会撤销已经保存的照片。
- 只从当前账号、当前宠物的真实生活记录重新解析来源。照护附件、用途未知附件、草稿、作品、示例、其他宠物/账号的引用均不进入此流程。浏览器校验IndexedDB键归属；原生分支拒绝网络地址，不做远端下载回退。

## 集中真机验收

1. 同一批PNG/JPEG/WebP原图，核对系统相册实际数量、尺寸、方向与文件内容；验证透明PNG是否保留透明通道。
2. 相册拒绝授权、空间不足、原文件缺失时停止或报告失败，旧记录仍在；检查相册后显式重试，不盲目重复已保存项。
3. 保存中返回、前后台切换、切账号/宠物、关闭进程再打开。已交给系统的一张可能完成，后续照片应停止；再次进入不恢复旧账号的临时选择。
4. 浏览器下载完成不等于系统相册保存，更不等于整库备份；本轮未实现换机恢复、云同步、视频导出或自动备份。

平台差异依据[DCloud图片API](https://uniapp.dcloud.net.cn/api/media/image.html#saveimagetophotosalbum)：App支持相册保存，H5不支持该接口，故使用浏览器下载。本轮未操作真实用户照片或相册。
