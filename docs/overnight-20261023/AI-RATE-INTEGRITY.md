# 咨询次数：并发上限与数据库回执

2026-10-23 08:17。本轮使用实际api_deepseek入口源码及本地数据库、模型、鉴权替身。未部署，未产生模型费用。

## 修改

咨询计数的读取仅接受明确成功、零或一条记录；错误响应与损坏结构不再被当作未使用次数。已有行校验文档ID、账号散列、日期、计数及可选窗口字段。旧记录缺少period/scope/plan仍兼容，必需身份和日期不能缺失或不符。

初始化必须取得正确id回执。原子加一必须收到一致的数值更新数量0或1；未知结果立即停止，不再自动加一次。加一后的读取必须确认计数已经增加，不能猜测剩余次数继续调用。仅明确的竞争失败0继续原有最多两轮检查。

可选会员查询发生异常时停止本次请求，不再静默切到免费计数。配置开关、每日3次和Plus每月300次均未改变。

## 仍然存在的限制

该计数接口按请求计数，没有请求级扣次凭据。写入成功而回执丢失可能占用一次但没有模型响应；用户再次发起请求仍可能再占用一次。没有增加自动退款或重发。后续需要稳定请求ID、响应恢复和旧版本兼容设计，不能简单把失败次数全部退回。

AI可选会员读取仍使用旧的identityHash文档路径和Plus映射，资料页使用userId/付费周期；Pro和可覆盖权益尚未统一。这个发布问题不能被本轮回执测试当作解决；本轮未打开会员查询、支付或其他生产开关，也未改真实权益。

本轮没有界面改动；最新H5仍为round-28各专项实测。真实云SDK、事务/并发服务行为和网络中断恢复需在隔离云环境验收。首页锁定文件未变。
