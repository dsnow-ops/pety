## 先看实际成果

1. **册页有真实月份目录了。** 保存的生活文字和照片自动形成时间章节，选择月份直接浏览并打开原记录。只有年份、月份或时间未详的旧记忆单独保留精度，不造日期，不复制私密全文索引。入口：陪伴册/纪念册 → 按月翻阅。
2. **照护后续可以连续回看。** 同一次咨询的多次观察分别保留，展开可见经过；新增表单不会默认复制上次症状；有未完成本机草稿时可以继续。怀念模式只读已有经过。切换宠物、账号或离开页面清除旧页面状态。
3. **补了三处可靠性缺口。** 文字整理后端的执行领取有独立凭据，旧执行器不能覆盖新的执行；资料查询故障不再冒充成功的空资料；旧格式记录和关联创作资料删除使用同一可恢复事务，避免第二次写入失败留下半删除状态。
4. **模型有9张对照（夜间6张＋V6一张＋原标准两张）。** 比较页见 [模型实验报告](../../experiments/native-alpha-20261023/report.html)。当前优先候选为 `pro-style-v3-01`，软3D更接近认可截图，但身份、透明残留和动画仍未达到完整交付要求。本实验累计新增保守预留2.10元，连同旧实验共3.50/20元；实际账单未核实。V6经明确授权执行后因材质退步淘汰，不替换V3。
5. **问诊摘要不再静默截掉第80条以后的记录。** 已复现并修复固定80条截断、同毫秒ID冲突、重复ID覆盖风险。界面每次展示30条，可以继续读旧记录；损坏的存储结构不会被当作空历史覆盖。已被旧版本丢弃的数据无法凭空恢复，本轮是防止后续继续丢失。设备空间不足仍可能导致新摘要保存失败，此时保留旧资料并明确提示。
6. **AI入口区分账号服务故障与失效令牌。** 临时账号/ 会话服务异常返回503，明确失效身份继续拒绝；返回错误码来自脱敏映射，避免原始异常透出。文字整理内部也按相同原则区分。本地入口与故障测试通过，仍未部署。
7. **会员查询异常不会伪造免费身份。** 合法空查询仍表示免费；缺少data、null记录、异常响应则报告服务不可用。没有改变价格、会员权益或有效期。

8. **损坏资料不会再被空白记录覆盖。** 创作容器、版本与旧日历保存增加严格检查；册页、日历、文字编辑器和制卡页有明确读取失败与重试状态。日历保存中途出错保留输入，制卡重试保留未保存版式。[专项证据与边界](READ-INTEGRITY.md)。

## 后端究竟还差在哪里

当前代码已经有官方令牌鉴权、会话、额度账本、支付订单骨架、预算和文件归属校验，不是完全空壳。但“有模块”与“可以稳定运营”之间仍有明显缺口。

| 优先级 | 当前可确认的差距 | 具体下一步与验收标准 |
|---|---|---|
| 发布前必须解决 | 历史报告记录过内置存储签名接口绕过归属校验；本轮没有重新验证远端是否已解决 | 用正式A/B身份、匿名身份与准确隔离测试文件，验证读/签名/过期/旧路径；不能只看匿名403。不得迁移或删除真实照片来制造通过 |
| 发布前必须解决 | 本轮后端源码与云端运行状态尚未对齐 | 准备按函数的发布清单与回滚材料；获明确部署授权后回读源码/Schema，再在隔离环境跑失败与并发矩阵 |
| 发布前必须解决 | 支付、OTP、单设备真实客户端链路、原生媒体和正式包仍缺验收 | 集中一次真机验收，单列官方支付沙箱与真实认证流程；不以本地替身计入云端通过 |
| 发布前必须解决 | AI入口旧会员读取和资料页的权益读取尚未统一，咨询计数缺少请求级恢复凭据 | 保持生产开关现状；建立同一授权契约、旧数据映射及权益等价矩阵，再接请求ID与未知结果恢复；不能只改一个免费/会员判断 |
| 产品长期使用 | 生活与创作资料主要在设备本地；云备份恢复、冲突合并、跨设备恢复未实现 | 先明确数据归属、版本冲突、删除语义、备份恢复演练，再接云同步；不能放一个“已同步”按钮假装完成 |
| 稳定运营 | 有局部错误码和测试，尚不能证明统一监控、告警和实际恢复时长 | 统一请求关联ID、脱敏错误分类、成功率/延迟/失败重试计数；故障演练确认报警能触达且能恢复 |
| 版本维护 | 工作区有大量历史未提交改动，证据与实现跨多个阶段 | 保留现状，按功能形成变更清单、已验证版本指纹和发布门槛；未经授权不提交、不清理历史 |
| 数字宠物体验 | 单张软3D候选未等于同身份、连续动作、原生透明视频 | 原始RGBA→身份风格确认→同主体动作测试→透明播放与功耗验证；每步有失败成本上限 |

## 为什么仍会感觉离成熟产品有距离

成熟度来自使用一段时间以后仍然可信：旧记录不丢，出错不会变成空白，换账号不串资料，付费任务不重复扣次，用户知道保存在哪里、失败之后怎么办。再堆几个入口只能增加表面宽度。本轮先补月份回看、完整照护经过、执行竞态与数据原子性，是在补这些连续使用中的断点。

与大型团队相比，我们还缺持续运营证据、跨设备数据恢复、正式发布流水线和长期性能数据。可以分阶段做，但不能把本地通过的测试数量当作这些能力已经具备。
