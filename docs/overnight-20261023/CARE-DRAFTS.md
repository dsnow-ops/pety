# 照护后续本机草稿：2026-10-23 05:35 阶段

入口：就医服务 → 原咨询下的「记录后续」。输入会尝试保存为该咨询的本机草稿；只有点击「记下这次观察」才新增正式经过。「稍后继续」收起并保留草稿，「放弃这次输入」丢弃对应未完成输入，保留正式历史。恢复草稿时明确显示“还未新增观察”。

## 实际实现

- 草稿位于当前账号、当前宠物的既有创作存储中，进一步绑定原咨询ID；不发送模型或云端。
- 草稿与正式记录分开识别。只有草稿的来源不会生成历史次数，也不会进入生活记录或制卡素材。
- 每次草稿写入有新版本令牌。另一页面已有较新草稿时，旧页的编辑、提交与删除都不能覆盖它。放弃旧页输入仅关闭旧编辑状态，较新草稿保留。
- 正式观察写入与对应草稿移除在同一次绑定存储写入中完成；同一个草稿提交结果不明时重试不会再新增一条。
- 怀念模式只能回看已有正式经过，不显示或修改草稿；离开页面清除可见输入和旧存储引用，下次按归属重新读取。
- 存储失败时不宣称保存成功，当前输入仍在页面，并提示保留当前页面后重试。
