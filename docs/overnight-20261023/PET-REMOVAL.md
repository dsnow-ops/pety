# 宠物本机删除事务与图片清理

2026-10-23。仅使用隔离浏览器中的合成 TEST 资料；没有删除真实宠物、真实照片或云资料。

## 修复了什么

原路径先更新宠物列表，再逐项删除历史，任何中途失败都可能留下半完成状态。分阶段对话、部分待处理状态也未纳入清理。现在先枚举当前账号已知的宠物键，检查旧键名冲突与媒体归属，再将列表、活动宠物、兼容字段、历史记录和图片清理队列放进同一可恢复本机事务。

确认弹窗显示之后，如果页面已离开、账号变化或宠物身份信息已变化，旧确认不能继续删除。旧键名可能同时属于另一只宠物时停止操作；损坏媒体元数据不被猜测处理。未管理的历史 URL 不进入图片删除队列。

元数据提交成功后才处理图片字节。IndexedDB 删除失败时，队列保留，用户可以明确重试；另一只宠物的图片和日记保持不变。App 图片删除校验账号、宠物、媒体键与专用目录文件名；App 目录规则不强加给其他平台的 saveFile 路径。删除最后一只宠物后不会由旧兼容缓存复活。

进一步故障检查发现，事务曾把明确保存的 null 和空字符串当作不存在，导致回滚丢失旧字段。已改为根据真实键清单记录是否存在；无法确认键清单或已存在值时停止事务。
