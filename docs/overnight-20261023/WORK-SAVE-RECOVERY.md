# 制卡作品保存与失败恢复

2026-10-23 10:29。只操作隔离TEST记录，没有真实资料或云端写入。

原先制卡页先写作品，再另写一次清除草稿。第二步失败时会显示“尚未存入”，但作品已经存在；写入完成后抛错再重试，也可能产生重复作品。现在作品和匹配草稿清理在同一份创作容器中一次提交。

当前页面为一次保存保留固定作品ID。写入结果不明时再次点击，会核对同一份冻结内容；已存在且相同则认回原作品，不再写入。已有ID对应不同内容时停止，不覆盖旧作品。保存后仍可由作品地址重新打开并绘制冻结画面。

如果草稿与当前渲染内容不同，作品仍按当前画面保存，同时保留那份草稿并明确提示。没有把内容不同的草稿直接当作旧草稿删除。未保存版式发生改变后使用新的作品内容，不误存此前失败的画面。
