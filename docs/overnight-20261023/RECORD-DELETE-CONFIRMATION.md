# 记录删除确认与关联资料保护

2026-10-23 10:55。所有删除均针对隔离TEST记录和测试IndexedDB内容，没有删除真实用户资料。

册页为显示的记录保留原始读取对象。打开删除确认前先核对该对象；确认期间再核对原记录、未完成草稿、相关制卡草稿和关联作品。旧列表或过期确认不能删除后来更新的内容。关联作品选择弹窗出现后新加入的作品也会让旧确认失效，用户需要重新查看后决定。

确认回调同时检查页面可见性、账号/宠物上下文和本次操作轮次。页面离开、上下文变化或身份存储读取失败时停止。无关记录和偏好变化不会无谓阻止当前删除。

删除旧日期记录时，其所属模式的日历草稿一并进入原有可恢复事务；另一模式草稿继续保留。媒体清理候选补上日历草稿及制卡草稿引用，避免这些草稿删除后遗漏照片。用户选择保留独立作品时，冻结内容及它引用的媒体继续保留。

## 范围与限制

这是对已经观察到的本机变化进行核对，不是跨进程互斥或云端删除协议。低层删除方法保留原有无确认参数调用兼容；实际册页删除入口使用确认计划。

元数据删除与日历草稿清理共用可恢复事务；媒体清理仍在元数据提交后执行。App在二者之间被系统终止时，可能留下未清理的本机文件，不能宣称已实现跨崩溃完整垃圾回收。真实原生文件删除、权限、前后台和系统返回仍待真机验收；H5的IndexedDB验证不能替代。
