# 生活文字草稿冲突与保留入口

2026-10-23 09:43。真实H5使用隔离浏览器和合成TEST记录，未操作真实宠物资料。

## 用户现在会看到什么

两个页面从同一条记录开始编辑时，旧页面不能再凭相同的编辑次数覆盖另一页的新草稿。冲突提示明确说明当前输入仅在此页，提供“另存为新记录”和“重新读取”。另存保留原记录及另一页草稿；写入失败保留输入和重试入口。重新读取要先确认，取消不替换输入。

确认重新读取后，输入框实际显示最新内容；不是只更新内部数据。另存成功转到新记录的地址，刷新仍能打开新记录。原有作品快照重新编辑时使用新的草稿版本，不继承旧编辑会话的版本状态。

## 数据层修复

草稿增加独立的持久化版本，区别于文字编辑次数。自动保存及正式保存都会检查当前草稿版本；正式记录已经有新版时，旧自动保存也被拒绝，不能把新版隐藏在旧草稿后面。删除的未完成草稿不能被延迟写入复活。

写入失败不推进调用方版本；写入已经完成但随后抛错时，重试可以确认相同内容并接回原版本，不再写一次。没有版本字段的合法旧草稿首次编辑时采用版本，后续同样受保护。保存冲突失败后停止衍生集合标记写入。
