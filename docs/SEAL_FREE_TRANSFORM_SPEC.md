# 自由印记 · 2026-09-29

保留右下、左下规范位置；自由放置永远是最后一项。朱印/压印继续使用原宠物专属像素资产，不生成新插画、不调用模型、不触碰额度。

## 字段与坐标

原配置 `presentation.seal.placement/style/size/enabled` 保留。自由时增量保存 `placement='free'`、`placementMode='free'`、`transformVersion=1`、`centerX/centerY`（0–1 纸面中心坐标）、`widthRatio`（0.06–0.38 纸宽）、`rotationDeg`（归一到 [-180,180)）、`pageIndex`（从 0 开始）、`zOrder='above-content'`。

纸面区域通过实际布局测量。拖动、角点和双指计算都转换到纸面归一坐标；旋转计算使用纸面高宽比，保持正方形印记等比缩放。CSS 交互与 Canvas 输出共用 `common/seal-transform.js` 的中心变换契约。Canvas save → 纸面 clip → translate 中心 → rotate → 绘制 → restore，控制框不参与绘制。

多页只在指定页盖章；目标页消失时报错，不能静默迁到别页。换版式需确认映射后的新版，取消保留旧配置与净图。预设切回自由以当前预设位置初始化；从自由切回预设清除自由字段，回到原布局规则。

## 交互和渲染

`FreeSealEditor` 使用已经渲染的无印记纸面 + 透明印记图层；每次移动只更新 CSS，完成后才调用真实 Canvas。手势结束一步撤销，touchcancel/失焦撤回当前未完成手势。重置/找回恢复进入时基准。大小/角度滑杆是替代操作。Android 实测中小印记角点覆盖拖动中心，已将角点移至选框外并使用 border-box。

选框与角点不进入预览净图、缩略图、存册、相册 PNG。缓存 payload 包括变换、样式、像素资产版本、页码、内容和账号/宠物作用域。作品存完整冻结 payload，重开不会用新名称或新布局覆盖旧作品。原 V1–V5 渲染器不重写；三种新作品使用 V6。

关闭健康、名字、照片和印记时，优先撤销敏感预览/缩略图/导出缓存，并关闭自由编辑层；取消面板或恢复前一版不能重新披露已关闭字段。名字关闭且旧印记未经无名字确认时，不允许该印记进入作品。

## 验证边界

数学回归包含 360/390/412 纸面映射、90/-45/180 度、缩放极限、多页指定页和正文完整性。H5 运行测试包含鼠标拖动、数值调整、真实下载、草稿重开和冻结作品重开。Android 的实际触控/相册/重启结果及构建哈希见本轮交付报告；坐标单元测试不能替代这些设备结果。
