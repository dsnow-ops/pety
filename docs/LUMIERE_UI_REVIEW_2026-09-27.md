# 归爪 Lumière Pet · UI 升级交付

本轮直接修改现有 uni-app/Vue3 工程。视觉依据是用户提供的四屏设计海报；没有收到额外独立的第三张首页文件，因此以海报首页的宠物主体、奶油色空间和下方照护入口为主方向。保留现有业务、账户、生成任务及纪念模式流程。

## 视觉方向与四页变化

以奶油米白、温暖灰米色、鼠尾草绿和深灰文字统一界面。首页让宠物占据主体，减少叠层、重阴影和重复按钮；问诊与账户页使用同一组安静的按钮和分隔；生成进行中独立进入深色空间，完成后回到浅色结果审阅。

## 图片融合与稳定性

- 使用原图舞台，主体保持清晰，不要求新图必须透明，也没有新增抠图流水线。
- 从图像边缘提取保守中性色，分别延展顶部与底部背景；底部再平缓接到页面奶油色。复杂、深色、高饱和边缘使用中性回退，避免把整页染脏。
- 停用旧的重复像素条拼接；空间模式不使用图像羽化遮罩。已有合格透明图仍可使用原有专属组件。
- 宠物、主资源、账号域、请求代次共同校验异步结果；切宠即清理旧配色与旧帧，页面隐藏后取消取色任务。
- 图片解码完成不再无限等待原生画布回调；450ms 后释放展示，取色最多额外重试一次。失效时保留占位与手动重试。
- 新增隐藏页面取色保护后，最终 Android 页面切换复查窗口未再观察到之前的原生画布 `$` 异常；这不是对所有设备的保证。

## 缓存与 CDN

沿用项目已有的账号隔离、App 私有文件缓存、150MB LRU、并发去重及文件保护机制，本轮着重修正其消费方式：

1. 首页与头像组件优先引用同一份已提交主图；宠物列表默认只加载当前宠物，其余项可复用已缓存文件，不主动拉满全部资源。
2. 可解析过期时间的签名 URL 按实际有效期复用，保留临近过期余量；不再统一每五分钟无意义刷新。无法识别有效期的地址仍保守处理。
3. 单次 WebView 解码失败先将本地文件标记待检查，重新验证已有文件；确认丢失或损坏才重新下载，减少切页抖动带来的重复流量。
4. 取色重试只读取当前本地图片，不启动新下载。当前宠物优先，没有加入全宠物预加载。

真机确认三只宠物的实际解码地址不同，首页往返问诊/我的后地址保持不变；日志确认已生成主图使用 App 私有缓存。地址稳定不等于实测 CDN 字节或账单，本轮不提供未经计量的节省比例。H5 主要依赖共享 URL 和浏览器缓存，没有声称具备与原生私有文件缓存同等的持久离线能力。
