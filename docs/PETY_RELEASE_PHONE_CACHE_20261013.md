# 10月13日真机切宠、返回与重启验收

用户最新要求：暂不做短信，继续其他验收。本轮没有发送短信、付款或生成图片。手机使用当前标准开发基座；不是正式签名 APK。

## 实际做了什么

在原有账号内，使用已有图片的两只宠物，连续执行20轮“切换宠物 → 首页 → 我的”。每轮保存切换后、首页、返回后的原始截图，分四组逐一检查首页和返回画面。奇数轮为猫、偶数轮为狗；稳定截图中的名称、头像和首页大图均对应当前宠物，记录数也随宠物对应切换，没有观察到稳定白屏或串宠。

首次预热切换时曾短暂显示文字占位，之后恢复已有形象。本次每步等待约1.2秒再截图，包含 ADB 通信开销，**不能证明首帧无闪烁或给出准确加载时延**。没有逐帧性能采样，也未比较原图像素质量。

完成后恢复原先选中的宠物，只重启本应用，没有清数据或退出账号。启动初次截图为基座启动画面；后续个人页与首页截图确认登录状态、四只既有宠物、原先当前宠物和图片恢复。未更改宠物资料、会员或记录。
