# 归爪 Lumière Pet 跨平台策略

## 当前判断

部分竞品可能更偏 iOS 原生实现，视觉动效、系统组件质感和页面转场会更接近 Apple 生态。

归爪当前阶段的核心优势不是先做单端极致，而是用 uni-app 尽快完成跨端产品闭环，覆盖 Android、iOS，并为后续鸿蒙、H5 等形态保留空间。

## 当前策略

1. 继续以 uni-app 作为主工程，先打通宠物档案、记录、聊天、纪念模式和电子宠物形象 mock 流程。
2. UI Foundation 以低饱和渐变、柔雾卡片、克制动效和清晰信息架构为基础，尽量接近原生高级感。
3. 关键体验优先保证跨端稳定，不为单一平台过早拆工程。
4. 真实 AI 图片生成、云端同步和会员支付仍在后续阶段接入。

## 后续可能

如果 iOS 用户验证结果明显更强，可以在产品路径稳定后，再考虑 SwiftUI 原生精修版。

当前阶段不拆 Swift 项目，避免过早增加维护成本。
