## 自由印记实际行为

规范位置仍是默认，自由放置在最后。支持拖动、等比角点旋转缩放及数值滑杆；可以压在照片、文字上，不强制吸附安全区。交互层不进入导出。预览、缩略图、存册和导出共用归一化纸面参数，旧作品仍使用冻结 payload 与旧版本渲染器。

Android 实际触控验证过拖动、角点旋转缩放、保存系统相册、重启恢复、存册重开。测得自由坐标 centerX=0.8160329411、centerY=0.6845745144，宽度为纸宽 0.161245818，角度 -42.614987°，第 1 页；参数见同名 payload.json。修复了小印记角点覆盖中心，导致拖动误触缩放的问题。双指手势只有数学测试，本轮未完成真实双指设备验收。

关闭健康、姓名、照片或印记时先撤下敏感预览及缓存；取消工具面板不会把已隐藏内容恢复。不兼容模板先确认，取消保持当前作品，确认创建明确变体。原文、历史作品和健康取材不随纸面开关改变。

实现契约：[自由印记规格](SEAL_FREE_TRANSFORM_SPEC.md)、[UI token 与组件职责](UI_SYSTEM_V2.md)。

## 单设备会话：实现与生效状态分开

服务端新增产品/UID 唯一活动会话、一次性验证票据、摘要凭证及版本比较事务。新设备完成正规身份验证后才获得短期确认票据；确认才接管，取消不影响旧会话。旧刷新不能创建新版本；旧退出不能撤销后来的设备。额度仍按原 UID、宠物及会员周期计算，会话检查与生成额度预留在同一受理事务内。

共享鉴权及登录、注册、刷新、退出、资料、会员、问诊、形象、私有媒体签名入口已接入；原支付未开放的门保持关闭。客户端收到失效先保存当前草稿，再锁定原账号作用域，不清业务数据、不把资料迁给游客。服务端状态未知时账号页明确显示尚未验证，见 [Android 账号页](ui-session-seal-20260929/android/30-account-state.png)。

**未部署开发云，未操作真实账号接管，未做真实 A/B 会话验证。当前不能宣称防共享已生效。** 还必须在开发云部署私有集合、全部相关函数及配套客户端，确认事务能力，并关闭客户端绕过网关签发受保护存储 URL 的权限。历史无持有回执照片需要受控归属迁移；已发 URL 的有效期不能被描述为立即撤销。严格模式默认未开启。具体入口和必要操作见 [单设备服务端规格](SESSION_SINGLE_DEVICE_SPEC.md)。

## 可直接操作的验收路线

1. 在现有 Android 开发基座正常打开首页，查看大幅宠物、场景内品牌与下滑收拢栏；“记录今天”和“AI 问诊”为同组主动作。
2. 点击“记录今天”，在“健康与观察”“日常与照片”填写同一天的虚构资料并保存；回到日期、问诊取材时仍按原健康语义读取。
3. 从这份记录进入制卡，先看成品。内容面板关闭姓名/照片/健康，确认旧预览立即更新或撤下。
4. 印记选择最末“自由放置”，拖动中心、角点旋转缩放，允许压在正文或照片上；完成后保存图片，核对没有控制框。存入册页、重启后重开核对位置。
5. 切换不兼容纸面，先取消，检查当前作品没变；再次确认，查看明确变体并可回到原版。
6. 查看档案的改名及 AI/原照片选择、册页作品封面、账号设置的服务端待验证状态。不要在真实账号上执行接管验证；需先准备确认过的开发云及虚构账号。
