## 可直接照着走的集中路线

建议先在 HBuilderX 将本项目运行到浏览器，用专门的虚构测试宠物：

1. 陪伴首页点“记下今天”，写“今天在窗边待了一会儿”，选“小习惯”标签；可选一张测试照片，点保存原文。
2. 点“看看册页”，查看“今天的一页”和图鉴来源。首页尝试提案“换一个/收藏/不适合/关闭”；册页可重新显示提案。若要测试三日，给同一虚构宠物分别保存本月 1/4/10 日记录，同日多条不加日数。
3. 在现有宠物档案流程把同一只测试宠物切为怀念；回首页确认没有周活动和提案。陪伴记录仍在该宠物册页。
4. 点“写给你”，只写“今天看到窗边，想起你。”，不填日期、不选照片。先保存原文。可选润色目前可检查登录/归属提示；成功候选要等开发云部署后再验，不能把当前失败提示当模型已通过。
5. 选“一句话”→预览→“存入册页”→导出。浏览器下载得到 1080 方图。另选信纸测试长文；几个片段需 2–4 张照片。预览显示的就是真实导出图。
6. 刷新页面，进入同一宠物册页，分别查看原文、草稿与已保存作品；打开作品重新预览。删除源记录时阅读提示，独立作品应继续存在。
7. 切换另一只测试宠物，确认不出现前一只的文字/照片/作品；回原宠物恢复。不要用真实资料做删除测试。
